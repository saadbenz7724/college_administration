# College Administration

A backend system built using NestJS for managing Students, Teachers, Classes, Subjects, and Attendance with Authentication, Authorization, Redis Caching, Kafka Event Streaming & DB Seeding.

---

## Tech Stack

| Technology | Purpose |
|-----------|---------|
| NestJS | Backend Framework |
| MySQL | Database |
| TypeORM | ORM |
| Redis | Caching |
| Kafka | Messaging Queue |
| Cron Job | Task Scheduling |
| JWT & Bcrypt | Authentication & Security |
